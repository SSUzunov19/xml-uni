# Задача 1: Карта на факултетите на СУ

Уеб страница с карта на факултетите на Софийски университет „Св. Климент Охридски“.
Приложението (Vite + React + OpenLayers + MUI) е предоставено от курса; задачата е да се
опишат данните във формат KML.

## Условие

Направете уеб страница с карта на факултетите на СУ.
За целта изтеглете архива, съдържащ уеб приложение,
показващо списък от обекти (факултети) на картата.

1.  Инсталирайте библиотеките и файловете, необходими за работа на приложението:

        npm install
        npm run test:install

2.  Стартирайте приложението:

        npm start

3.  Отворете http://localhost:5173/ в уеб браузър
4.  Изпълнете тестовете:

        npm test -- --ui

5.  Страницата прочита данните за факултетите от `maps/faculties.kml`.
    Този файл е празен, затова и списъкът с факултети е празен.
6.  Използвайте речника, дефиниран от [KML формата],
    за да създадете XML документ съдържащ следните факултети:
    -   Стопански факултет.
        Адрес: София 1113, бул. Цариградско шосе 125.
        GPS координати: 23.363992, 42.672976.
    -   Исторически факултет.
        Адрес: София 1504, бул. Цар Освободител 15.
        GPS координати: 23.335206, 42.693023.
    -   Факултет по математика и информатика.
        Адрес: София 1164, бул. Джеймс Баучър 5.
        GPS координати: 23.330584, 42.674396.
7.  Факултетите трябва да са видими на картата и всички тестове да минават успешно
8.  Отворете `maps/faculties.kml` в [Google Earth]

  [KML формата]: https://developers.google.com/kml/
  [Google Earth]: https://earth.google.com/web/

## Решение

Решението е файлът [`maps/faculties.kml`](maps/faculties.kml). Всеки факултет е `Placemark`
с `name`, `address` и `Point`; трите са събрани в общ `Document`:

```xml
<kml xmlns="http://www.opengis.net/kml/2.2">
    <Document>
        <name>Факултети на СУ „Св. Климент Охридски“</name>
        <Placemark>
            <name>Факултет по математика и информатика</name>
            <address>София 1164, бул. Джеймс Баучър 5</address>
            <Point>
                <coordinates>23.330584,42.674396</coordinates>
            </Point>
        </Placemark>
        <!-- Стопански и Исторически факултет -->
    </Document>
</kml>
```

- Пространството от имена `http://www.opengis.net/kml/2.2` е задължително — без него
  OpenLayers не разпознава елементите.
- Координатите са във формат `дължина,ширина` (lon,lat), както ги изисква KML.
- Приложението показва `name` в падащия списък, а `address` — в детайлите за избрания факултет.

Повече за формата: [`notes/kml.md`](../notes/kml.md).

## Стартиране

```sh
npm install
npm run test:install
npm start      # http://localhost:5173/
npm test       # или npm test -- --ui
```

## Тестове

Тестовете (Playwright, Chromium) проверяват:

| Тест | Какво проверява | Резултат |
|------|-----------------|----------|
| списък с факултетите | имената в падащия списък | минава |
| избор на факултет | адреса на всеки избран факултет | минава |
| екранни снимки (`faculties-list.png`, `faculty-details.png`) | вида на страницата спрямо еталонни снимки | разлика в изглаждането на шрифта |

Еталонните снимки в `tests/__screenshots__/` са направени на друга операционна система.
На macOS и Linux разположението на елементите съвпада, но изглаждането (anti-aliasing) на
текста е различно, затова сравнението пиксел по пиксел отчита разлика. Данните и
функционалността са коректни; снимките не са подменяни.
