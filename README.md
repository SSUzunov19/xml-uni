## Как се стартира

Задачите с уеб приложение използват [Node.js](https://nodejs.org/) (препоръчително LTS версия)
и се стартират от собствената си папка:

```sh
cd 01-su-faculties-map

npm install            # инсталира зависимостите
npm run test:install   # инсталира браузъра за Playwright (Chromium)
npm start              # стартира приложението на http://localhost:5173/
npm test               # пуска тестовете (с интерфейс: npm test -- --ui)
```

## IntelliJ IDEA

Проектът се отваря директно: **File → Open…** и избирате папката на хранилището.

- **Run конфигурации** (горе вдясно): `01 install`, `01 test:install`, `01 start`, `01 test`.
  Те пускат npm скриптовете на задача 1 и не изискват терминал.
- **XML схеми**: пространството от имена на KML е свързано с локалната схема в
  [`schemas/kml-2.2.0/`](schemas/). Така в `.kml` файловете работят автодовършването и
  валидацията (**Tools → XML Actions → Validate**).
- `node_modules`, `dist`, `test-results` и `playwright-report` са изключени от индексирането.
- Форматирането следва [`.editorconfig`](.editorconfig) (4 интервала, UTF-8, LF).

Изисква се Node.js интерпретатор: **Settings → Languages & Frameworks → Node.js**.

## Знания и бележки

| Тема | Бележки | Използвана в |
|------|---------|--------------|
| KML (Keyhole Markup Language) | [`notes/kml.md`](notes/kml.md) | Задача 1 |

Накратко за KML:

- XML речник за географски данни; пространство от имена `http://www.opengis.net/kml/2.2`.
- Основна структура: `kml` → `Document` → `Placemark` (`name`, `address`, `Point/coordinates`).
- В `coordinates` редът е **дължина,ширина[,височина]** (lon,lat) — обратно на обичайното „ширина, дължина“.
- Файлът може да се провери директно в [Google Earth](https://earth.google.com/web/).
